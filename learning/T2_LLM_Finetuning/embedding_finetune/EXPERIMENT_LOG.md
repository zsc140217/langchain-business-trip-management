# Embedding微调实验记录

## 实验概况

**实验时间**: 2026-06-12  
**模型**: BAAI/bge-large-zh-v1.5 (1.3GB)  
**任务**: 差旅政策检索增强（RAG场景）  
**框架**: sentence-transformers 5.5.1 + PyTorch 2.12.0

## 实验参数与结果

### 实验1：基础微调
- **训练样本**: 10条 (20个样本对)
- **Batch Size**: 8
- **Epochs**: 3
- **训练时间**: ~10分钟
- **结果**: 基础80% → 微调80% (提升0%)

### 实验2：改进版微调
- **训练样本**: 30条 (60个样本对)
- **Batch Size**: 4
- **Epochs**: 5
- **训练时间**: ~20分钟
- **结果**: 基础80% → 微调80% (提升0%)
