# 前端测试截图指南

## 📋 准备工作

### 启动服务
```bash
# 启动 Docker
docker-compose up -d

# 启动后端
python src/api/main.py

# 获取Token
curl -X POST http://localhost:8000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username": "employee", "password": "password123"}'
```

## 🧪 测试用例

### 1. 政策问答（RAG检索）
**输入**：`北京的住宿标准是多少？`  
**预期**：展示召回混合检索，返回职级对应标准  
**截图**：完整对话气泡，响应时间<5秒

### 2. 自动审批（金额<阈值）
**输入**：`我要报销去北京出差的费用，3天，花了800元`  
**预期**：自动通过，显示阈值计算（350×3=1050）  
**截图**：绿色成功提示，审批详情

### 3. 人工审批（金额≥阈值）
**输入**：`我要报销去深圳出差的费用，5天，花了2500元`  
**预期**：需人工审批，推送飞书卡片  
**截图**：橙色警告提示，超出原因

### 4. 天气查询（工具调用）
**输入**：`北京明天天气怎么样？`  
**预期**：调用和风天气API，返回格式化天气信息  
**截图**：天气详情，数据来源标识

### 5. 酒店查询（飞猪API）
**输入**：`推荐北京的酒店`  
**预期**：飞猪数据，3-5家酒店列表，符合标准建议  
**截图**：飞猪标识，酒店列表

### 6. 审批状态查询（记忆追踪）
**输入**：`我的审批进度怎么样了？`  
**预期**：查询待审批记录，显示状态详情  
**截图**：审批记录列表

## 📸 截图规范

**内容**：完整对话气泡，避免无关内容

## 🔍 故障排查

- **401错误**：重新登录获取Token
- **审批卡住**：检查`.env`中`FEISHU_WEBHOOK_URL`
- **返回模拟数据**：配置`QWEATHER_API_KEY`/`FLYAI_API_KEY`
