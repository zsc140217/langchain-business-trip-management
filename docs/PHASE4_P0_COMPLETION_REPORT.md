## 完成内容

### 1.1 PostgreSQL 审批记录表

**文件**: scripts/init_db.sql

新增 pproval_records 表，包含以下字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| approval_id | VARCHAR(50) UNIQUE | 审批单号 (APVYYYYMMDDXXX) |
| user_id | VARCHAR(255) | 用户 ID |
| destination | VARCHAR(255) | 出差目的地 |
| days | INTEGER | 出差天数 |
| amount | NUMERIC(10,2) | 报销金额 |
| status | VARCHAR(20) | 审批状态: pending/approved/rejected |
| approver | VARCHAR(255) | 审批人 |
| comment | TEXT | 审批备注 |
| submitted_at | TIMESTAMP | 提交时间 |
| approved_at | TIMESTAMP | 审批完成时间 |

索引:
- idx_approval_records_user_id — 按用户查询
- idx_approval_records_status — 按状态过滤
- idx_approval_records_submitted_at — 按时间排序
- idx_approval_records_approval_id — 单号查找

### 1.2 ApprovalDBService 数据库持久化层

**新增文件**: src/agents/approval_db_service.py

提供两个核心方法：
- save_approval_record() — 写入/更新审批记录（UPSERT）
- update_approval_status() — 更新审批状态（如人工审批完成后回调）

设计要点：
- 数据库不可用时静默降级（log warning，不阻塞审批流）
- 连接字符串默认从 APPROVAL_DB_URL 或 DATABASE_URL 环境变量读取
- 使用 psycopg2 连接 PostgreSQL

### 1.3 ApprovalEngine 集成

**文件**: src/agents/approval_engine.py

- 构造函数新增 db_service: Optional[ApprovalDBService] 参数
- _auto_approve(): 审批通过后调用 self._save_to_db(approval_info, status="approved", ...)
- _manual_approval(): 提交人工审批后调用 self._save_to_db(approval_info, status="pending", ...)

### 1.4 AlertManager 超时告警

**文件**: monitoring/alerts.yml

新增告警规则：
`yaml
- alert: ApprovalPendingTimeout
  expr: travel_agent_pending_approval_max_hours > 24
  for: 5m
  labels:
    severity: warning
    category: approval
  annotations:
    summary: "审批超时检测"
    description: "手动审批单待处理超过 {{  }}小时，阈值24小时"
`

对应的 Gauge 指标：
- 	ravel_agent_pending_approval_max_hours{type="manual"} — 手动审批待处理最大时长
- 	ravel_agent_pending_approval_max_hours{type="auto"} — 自动审批待处理最大时长
