## 核心特性

### 1. 智能查询分类
- 使用LLM判断查询意图
- 返回类型、置信度和原因
- 启发式规则作为后备

### 2. 自适应检索决策
- CHITCHAT：直接LLM回答，无需检索
- FACTUAL：执行RAG检索，返回来源文档
- 动态优化响应速度和准确性

### 3. 完整返回结构
```python
{
    "answer": "回答内容",
    "retrieved": bool,  # 是否执行了检索
    "sources": [Document],  # 来源文档列表
    "classification": {
        "type": "FACTUAL/CHITCHAT",
        "confidence": float,
        "reason": str
    }
}
```

### 4. 健壮的错误处理
- 输入验证（空查询、None查询）
- JSON解析容错
- 启发式规则后备
- 空文档处理

## Self-RAG vs 传统RAG

| 维度 | 传统RAG | Self-RAG |
|------|---------|----------|
| 检索策略 | 所有查询都检索 | 智能判断是否检索 |
| 响应速度 | 较慢（每次都检索） | 更快（闲聊直接回答） |
| 成本 | 高（不必要的检索） | 低（按需检索） |
| 用户体验 | 一般 | 更好 |
| 准确性 | 依赖检索质量 | 分场景优化 |

## 使用方法

### 基本使用

```python
from src.rag.self_rag import SelfRAG
from src.rag.retriever import create_vectorstore, get_retriever
from src.rag.loader import load_documents_from_text

# 准备文档
docs = load_documents_from_text(text, chunk_size=200)
vectorstore = create_vectorstore(docs)
retriever = get_retriever(vectorstore, k=3)

# 创建Self-RAG
self_rag = SelfRAG(retriever=retriever)

# 查询
result = self_rag.query("去上海出差住宿能报多少钱")
print(result["answer"])
print(f"是否检索: {result['retrieved']}")
```

### 单独使用分类器

```python
from src.rag.query_classifier import QueryClassifier

classifier = QueryClassifier()
result = classifier.classify("你好")
print(f"类型: {result['type']}")
print(f"置信度: {result['confidence']}")
```
