### P0 - 飞书双向交互 ⭐ 核心
**时间:** 6-8小时

**功能描述：**
系统与飞书完整双向通信：
1. 提交报销 → 系统推送卡片到飞书审批人
2. 审批人点击飞书卡片按钮 → 飞书回调系统更新状态
3. 状态更新后自动流转到下一审批人

**前置准备：**

1. **飞书开放平台：** https://open.feishu.cn/
   - 创建企业自建应用
   - 获取凭证：`APP_ID`、`APP_SECRET`
   - 配置权限：发送消息、获取用户信息、互动卡片
   - 配置回调URL：`https://your-domain.com/api/reimbursement/feishu/callback`

2. **环境变量配置：** `.env`
   ```bash
   FEISHU_APP_ID=cli_xxxxxxxxxxxxx
   FEISHU_APP_SECRET=xxxxxxxxxxxxxxxxxxxxx
   FEISHU_VERIFICATION_TOKEN=xxxxxxxxxxxxx
   FEISHU_ENCRYPT_KEY=xxxxxxxxxxxxx  # 用于回调验证
   ```

**实现文件清单：**

**阶段1：卡片设计与推送（3小时）**

1. **新建文件：** `src/reimbursement/feishu_card_template.py`
   - 函数：`build_approval_card()` - 构建交互式卡片JSON
   - 包含：标题、报销信息、发票数量、通过/拒绝按钮
   - 按钮value携带：`application_id` 和 `action`

2. **修改文件：** `src/reimbursement/feishu_approval_client.py`
   - 已有类：`FeishuApprovalClient`
   - 新增方法：`send_approval_card(user_id, card_content)` - 推送卡片
   - 新增方法：`get_access_token()` - 获取飞书token
   - API endpoint: `https://open.feishu.cn/open-apis/im/v1/messages`

3. **修改文件：** `src/reimbursement/reimbursement_service.py`
   - 函数：`submit_application()`
   - 在创建审批链后，调用 `feishu_client.send_approval_card()`
   - 推送给第一个审批人

**阶段2：回调接收与处理（3小时）**

4. **修改文件：** `src/api/reimbursement_api.py`
   - 已有函数：`handle_feishu_callback()` （第363-423行）
   - 当前状态：已有框架，待完善
   - 需要实现：
     - 解析飞书回调数据
     - 验证签名（安全性）
     - 提取 `application_id` 和 `decision`
     - 调用 `reimbursement_service.approve()`
     - 返回toast提示

5. **测试文件：** `tests/test_feishu_callback.py` （新建）
   - Mock飞书回调请求
   - 测试通过/拒绝两种场景
   - 测试多级审批流转

**阶段3：审批流转（2小时）**

6. **修改文件：** `src/reimbursement/reimbursement_service.py`
   - 函数：`approve()` 
   - 审批通过后检查是否有下一审批人
   - 如有，推送卡片给下一审批人
   - 如无，标记为最终通过，生成PDF

7. **修改文件：** `src/reimbursement/approval_chain_engine.py`
   - 函数：`get_next_approver(application_id, current_level)`
   - 返回下一级审批人信息

**关键数据流：**

```
【提交阶段】
ReimbursementService.submit_application()
  ↓
ApprovalChainEngine.match_chain()  # 匹配审批链
  ↓
FeishuApprovalClient.send_approval_card()  # 推送给第1审批人
  ↓
保存到 reimbursement_approvals 表


【审批阶段】
飞书用户点击按钮
  ↓
飞书POST回调到 /api/reimbursement/feishu/callback
  ↓
解析: application_id, decision, approver_id
  ↓
ReimbursementService.approve()
  ↓
更新 reimbursement_approvals 表
  ↓
如果有下一级 → 推送卡片给下一审批人
  ↓
如果全部通过 → 生成PDF，更新状态为approved
```

**验收标准：**
- [ ] 提交报销后，第一审批人飞书收到卡片
- [ ] 卡片显示完整信息（金额、出差地、发票数）
- [ ] 点击"通过"按钮，系统状态变为approved
- [ ] 点击"拒绝"按钮，系统状态变为rejected
- [ ] 多级审批：第一级通过后自动推送给第二级
- [ ] 全部通过后自动生成PDF
- [ ] 卡片按钮点击后显示toast反馈

**注意事项：**
1. 飞书回调需要配置公网域名（本地开发可用 ngrok）
2. 签名验证必须实现（防止伪造请求）
3. 审批人的 `user_id` 需要是飞书的 `open_id` 或 `user_id`
4. 测试时需要真实的飞书账号和企业应用
