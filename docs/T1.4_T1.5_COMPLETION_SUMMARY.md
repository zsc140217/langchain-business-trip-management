## 💡 核心知识点

### 1. interrupt() 工作机制

**与普通input()的区别**：

| 特性 | `input()` | `interrupt()` |
|------|----------|--------------|
| 阻塞方式 | 同步阻塞，进程卡住 | 异步中断，进程可退出 |
| 状态保存 | ❌ 不保存 | ✅ 保存到checkpointer |
| 分布式支持 | ❌ 不支持 | ✅ 支持（可在不同进程恢复）|
| 必需依赖 | 无 | **checkpointer** |

**代码示例**：
```python
from langgraph.types import interrupt

def approval_node(state):
    # 暂停执行，等待外部输入
    decision = interrupt({
        "question": "是否批准？",
        "details": state
    })
    
    # 恢复执行时，decision接收到用户输入
    return {"status": "approved" if decision else "rejected"}
```

**执行流程**：
```python
# 第一次执行 - 遇到interrupt暂停
try:
    graph.invoke(state, config={"configurable": {"thread_id": "123"}})
except GraphInterrupt:
    print("等待审批...")

# 恢复执行 - 提供审批决策
result = graph.invoke(
    {"approval_decision": True},  # 提供interrupt等待的输入
    config={"configurable": {"thread_id": "123"}}
)
```

### 2. 条件路由函数

**返回值是节点名称字符串**（不是布尔值）：

```python
def needs_approval(state: TravelAgentState) -> str:
    """检查是否需要审批"""
    if state.get("needs_approval"):
        return "approval_node"  # 返回节点名称
    else:
        return "answer_node"    # 返回节点名称

def after_approval(state: TravelAgentState) -> str:
    """根据审批结果路由"""
    if state.get("approval_decision") is True:
        return "process_approval_node"
    else:
        return "answer_node"
```

**配置条件边**：
```python
graph_builder.add_conditional_edges(
    "check_approval_node",
    needs_approval,  # 条件函数
    {
        "approval_node": "approval_node",
        "answer_node": "answer_node"
    }
)
```

### 3. stream() vs invoke()

**对比**：

| 特性 | `invoke()` | `stream()` |
|------|-----------|-----------|
| 返回方式 | 一次性返回最终结果 | 实时返回每个节点结果 |
| 数据结构 | `dict` (完整状态) | `Generator[dict]` (chunk流) |
| 阻塞 | 阻塞直到全部完成 | 逐个节点yield |
| 适用场景 | 批处理、离线任务 | 实时反馈、长耗时任务 |

**代码示例**：
```python
# invoke - 等全部完成
result = graph.invoke(state)
print(result["answer"])  # 15秒后才输出

# stream - 边执行边返回
for chunk in graph.stream(state):
    for node_name, state_update in chunk.items():
        print(f"{node_name}: {state_update}")
        # rewrite: {...}      (2秒后)
        # retrieve: {...}     (5秒后)
        # agent: {...}        (10秒后)
        # answer: {...}       (15秒后)
```

### 4. 解决微信5秒超时

**问题**：微信消息5秒超时，Agent Loop执行需要15秒

**解决方案**：流式输出 + 实时推送

```python
@app.post("/wechat/webhook")
async def handle_message(msg: WeChatMessage):
    # 1. 立即回复"处理中"（避免超时）
    await send_wechat_message("正在查询，请稍候...")
    
    # 2. 异步流式执行
    for chunk in graph.stream(state, config):
        node_name, update = list(chunk.items())[0]
        
        # 3. 实时推送进度
        if node_name == "rewrite":
            await send_wechat_message("正在优化问题...")
        elif node_name == "retrieve":
            await send_wechat_message("正在检索政策...")
        elif node_name == "agent":
            await send_wechat_message("正在分析...")
        elif node_name == "answer":
            await send_wechat_message(f"✅ {update['answer']}")
```

## 🔍 实战案例

### 案例1：审批流程

**输入**：
```python
query = "我要去美国出差7天，预算8000元"
state = {
    "query": query,
    "budget": 8000,
    "days": 7,
    "destination": "美国"
}
```

**执行流程**：
```
1. rewrite_node → 查询改写
2. retrieve_node → 检索文档（5个）
3. check_approval_node → 检查审批条件
   触发条件：days=7 > 5天标准
   设置：needs_approval=True
4. needs_approval() → 路由到 approval_node
5. approval_node → interrupt() 暂停
   ⏸️ 图在此处中断，等待外部输入
```

**状态保存**（checkpointer）：
```python
{
  'query': '我要去美国出差7天，预算8000元',
  'budget': 8000,
  'days': 7,
  'destination': '美国',
  'needs_approval': True,
  'approval_reason': ['出差天数超限：7天 > 5天标准'],
  'documents': [...]  # 5个检索到的文档
}
```

**恢复执行**：
```python
# 提供审批决策
graph.invoke(
    {"approval_decision": "approve"},
    config={"configurable": {"thread_id": "test-001"}}
)

# 继续流程：
# 6. approval_node 接收 decision="approve"
# 7. after_approval() → 路由到 process_approval_node
# 8. process_approval_node → 处理审批通过逻辑
# 9. agent_node → LLM生成最终答案
# 10. answer_node → 返回答案
```

## 🐛 遇到的问题和解决

### 问题1：interrupt必须配合checkpointer

**错误**：
```python
graph = workflow.compile()  # 没有传checkpointer
# 使用interrupt() → 报错或状态丢失
```

**解决**：
```python
from langgraph.checkpoint.memory import MemorySaver

checkpointer = MemorySaver()
graph = workflow.compile(checkpointer=checkpointer)
```

### 问题2：条件函数返回值理解错误

**错误理解**：返回布尔值
```python
def needs_approval(state) -> bool:
    return state.get("needs_approval")  # ❌ 错误
```

**正确理解**：返回节点名称字符串
```python
def needs_approval(state) -> str:
    if state.get("needs_approval"):
        return "approval_node"  # ✅ 返回节点名称
    return "answer_node"
```

### 问题3：Vectorstore检索返回0文档

**原因**：
1. Embedding模型不一致（构建用v2，加载用v1）
2. 检索API过时（`get_relevant_documents` → `invoke`）

**解决**：
```python
# 1. 统一embedding模型
embeddings = DashScopeEmbeddings(
    model="text-embedding-v2",  # 构建和加载都用v2
    dashscope_api_key=api_key
)

# 2. 使用新API
docs = retriever.invoke(query)  # ✅ 新API
```
